# PR description
Fill the Valere PR template for the changes on this branch compared with `develop`:
- **Title**: Conventional Commit format with ticket ID
- **What**: what changed, in plain words
- **Why**: link to the ticket and the reason
- **How tested**: tests added and manual steps
- **Screenshots**: say "add screenshots" if UI changed
- **AI-generated parts**: list which files or parts were mostly written by Cursor
- **Risks / rollback**: migrations, config changes, how to roll back
Only state things that are true from the diff. Mark anything you are unsure of with [CHECK].
