# Commit message
Write a commit message for the staged changes using Conventional Commits:
`type(scope): short summary [TICKET]`
- type: feat, fix, refactor, perf, test, docs, chore or ci
- summary: imperative, lowercase, max 72 characters
- If the change is large, add a short body with bullet points of what and why.
Ask me for the ticket ID if you cannot find it in the branch name.
